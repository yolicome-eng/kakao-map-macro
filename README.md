# 카카오맵 즐겨찾기 자동 등록

Windows EXE로 실행하는 프로그램입니다.

1. Chrome 시작 / 로그인
2. Chrome에서 카카오 로그인 및 2차 인증
3. 엑셀 선택
4. 그룹 새로고침
5. 그룹 선택 후 등록 시작

엑셀은 첫 행을 제목으로 사용하며 5개 열이 필요합니다.
1열 순번 / 2열 선로명 / 3열 선로번호 / 4열 전산화번호 / 5열 주소

결과와 실패목록은 %APPDATA%\\KakaoFavoriteMacro 아래에 저장됩니다.

주의: 카카오맵 화면이나 내부 동작이 변경되면 매크로를 수정해야 할 수 있습니다. 첫 실행은 소량으로 테스트하세요.
